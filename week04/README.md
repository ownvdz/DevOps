경로

&#x20;- 절대 경로: 루트(/)부터 시작. 어디서 실행해도 같음

&#x20;- 상대 경로: 현재 위치 기준       (  . 현재 / .. 상위 / \~ 홈 )



cd "$(dirname "$0")": 스크립트를 어디서 호출하든 스크립트가 있는 위치 기준으로 실행하기 위해 사용



find, grep, 파이프

&#x20;- find : 조건에 맞는 파일 찾기 (-type d는 디렉터리만)

&#x20;- grep : 패턴이 포함된 줄을 검색

&#x20;- | (파이프): 앞 명령의 표준 출력을 뒤 명령의 표준 입력으로 연결

&#x20;- > 리다이렉션: 결과를 파일로 저장. 

&#x09;예) grep ERROR server.log > errors.txt



Git 협업

&#x20;- 브랜치 : 실패해도 안전한 공간

&#x20;- Pull Request : 코드 리뷰

&#x20;- CI : 컴퓨터가 자동으로 검사



브랜치

&#x20;- main은 기준이 되는 안정적인 브랜치

&#x20;- 기타 브랜치는 내 작업실 (터져도 main은 안전)



Conflict

&#x20;- 원인: 공통 조상 A에서 갈라진 B와 C가 같은 줄을 서로 다르게 수정

&#x20;- Git이 모르는 것이 아니라 함부로 결정하지 않는 것. 무엇을 남길지 사람이 결정해야 함
