	./start.sh 로 실행 (이름만 쓰면 PATH에 등록된 디렉터리에서 찾음)

셸 스크립트
 - #! (shebang): 어떤 인터프리터로 실행할지 OS에 알려줌. 첫 줄에 작성
 - $0: 실행한 스크립트의 경로
 - dirname: 경로에서 디렉터리 부분만 출력
 - $( ) : 명령어 치환. 명령의 출력을 그 자리에 넣음
 - || exit 1 : 앞 명령이 실패하면 상태코드 1로 종료 (종료 상태 0 = 성공, 그 외 = 실패)
 - exec: 현재 bash를 python3로 대체


조건문

 - command -v : 명령어가 존재하면 경로 출력, 없으면 실패 상태 반환
 - >/dev/null : 출력 버리기 (출력을 null으로 보내버림)
 - 2>&1 : 표준 오류를 표준 출력이 가는 곳으로 보냄
 - >&2 : 메시지를 표준 오류로 출력 / exit 1 : 실패 상태로 종료 (둘은 다른 것)
 - 0: 표준입력, 1: 표준출력, 2: 표준오류
